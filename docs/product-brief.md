# Bronze IQ — Product Brief

## Propuesta central

> "Menos improvisación. Más control. Bronceado con cabeza."

Bronze IQ es una app móvil para iOS y Android que ayuda al usuario a gestionar su exposición solar de forma más consciente, prudente y controlada.

La app no busca que el usuario tome más sol. La app busca que el usuario deje de improvisar.

---

## Qué hace Bronze IQ

- Ayuda a registrar sesiones de exposición solar
- Revisa el historial reciente y detecta acumulación
- Identifica señales de exceso (enrojecimiento, quemadura, incomodidad)
- Ofrece orientación prudente y determinista
- Construye un hábito más responsable
- Proporciona una experiencia visual premium y sencilla

---

## Qué NO es Bronze IQ

Bronze IQ **no es** y **nunca debe presentarse como**:

- Una app médica
- Un diagnóstico dermatológico
- Una herramienta clínica
- Una app que garantice seguridad solar
- Una app que diga "puedes tomar el sol sin riesgo"
- Una app de "ponte moreno rápido"
- Una app de retos o gamificación agresiva
- Una app que sustituya al dermatólogo
- Una app de análisis de piel por imagen
- Una app de predicción exacta de daño solar
- Una simple calculadora de minutos

**Lo que no quiere:**

## Principios éticos y de seguridad (obligatorios)

### 1. Prudencia por defecto

Cuando haya duda, la app recomienda menos exposición, descanso o precaución.

### 2. Sin absolutismo

Nunca usar frases como: "es seguro", "sin riesgo", "garantizado", "puedes tomar el sol sin problema", "tiempo seguro".

### 3. Transparencia

La app explica por qué recomienda algo.

### 4. Control del usuario

El usuario puede revisar sus datos, editar perfil, cerrar sesión y solicitar eliminación de datos.

### 5. Minimización de datos

Solo guardar lo estrictamente necesario para el MVP.

### 6. Recomendaciones auditables

Las recomendaciones del MVP son deterministas, transparentes y testeables. Sin IA opaca, sin ML, sin LLM.

### 7. Sin incentivo peligroso

Prohibido: rachas, rankings, retos de exposición, recompensas por más sol, gamificación agresiva.

### 8. Lenguaje prudente

La app orienta, no diagnostica.

## Decisiones cerradas del MVP

| Decisión             | Valor                                       |
| -------------------- | ------------------------------------------- |
| Plataformas          | iOS + Android                               |
| Stack                | Expo + React Native + TypeScript + Supabase |
| Auth                 | Obligatoria, sin modo guest                 |
| Fototipo Fitzpatrick | En perfil, **opcional**, no bloquea uso     |
| Recomendaciones      | Deterministas, sin IA ni LLM                |
| UV                   | Manual opcional, sin API externa            |
| Idioma UI            | Español                                     |
| Idioma código        | Inglés                                      |
| Monetización         | Fuera del MVP                               |

## Funcionalidades exactas del MVP

1. Splash / loading inicial
2. Welcome
3. Onboarding prudente (3 pasos)
4. Disclaimer / aceptación (obligatorio)
5. Registro y login
6. Creación de perfil básico (alias, objetivo, sensibilidad, fototipo opcional)
7. Home con recomendación y resumen
8. Registro de sesión de exposición
9. Recomendación prudente determinista
10. Historial de sesiones
11. Detalle básico de sesión
12. Ajustes
13. Edición de perfil
14. Pantalla de disclaimer completo
15. Cierre de sesión
16. Solicitud de eliminación de datos
